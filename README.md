# Flipkart Mobile Products Web Scraping & Data Analysis

## Project Overview

This project focuses on web scraping mobile phone product data from Flipkart
and performing data analysis using Python.

A dataset of 24 mobile phone products was collected and analyzed based on
product name, rating, rating count, review count, RAM, storage, price,
original price and discount.

## Objectives

- Scrape mobile phone product data from Flipkart.
- Clean and preprocess the scraped data.
- Perform Exploratory Data Analysis (EDA).
- Create meaningful visualizations.
- Identify business insights and trends.
- Provide useful recommendations.

## Tools & Technologies

- Python
- Jupyter Notebook
- Requests
- BeautifulSoup
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains 24 mobile phone products with the following attributes:

- Product Name
- Rating
- Rating Count
- Review Count
- RAM
- Storage
- Price
- Original Price
- Discount

## Key Findings

- Higher-priced mobile phones generally have higher ratings.
- Rating Count and Review Count have a strong positive relationship.
- Higher RAM configurations generally have higher prices.
- Higher storage configurations generally have higher prices.
- Price and Original Price have a very strong positive relationship.
- Discount and Rating have a very weak relationship.

## Conclusion

This project demonstrates an end-to-end web scraping and data analysis
workflow, including data collection, data cleaning, EDA, visualization
and business insights.

The analysis provides useful information about mobile phone pricing,
customer ratings, reviews, RAM, storage and discounts.
